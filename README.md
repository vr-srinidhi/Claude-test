# Claude-test — Hello World Website

A simple Hello World static website built with HTML and CSS.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 |
| Styling | CSS3 |
| Server | Python 3 (built-in `http.server`) |

## How to Run

**Requirements:** Python 3 (pre-installed on most systems)

1. Clone the repository:
   ```bash
   git clone https://github.com/vr-srinidhi/Claude-test.git
   cd Claude-test
   ```

2. Start the local server:
   ```bash
   python3 -m http.server 8080
   ```

3. Open your browser and go to:
   ```
   http://localhost:8080
   ```

## Where to Launch

| Environment | URL |
|-------------|-----|
| Local | http://localhost:8080 |

To use a different port, replace `8080` with any available port number:
```bash
python3 -m http.server 3000
```
